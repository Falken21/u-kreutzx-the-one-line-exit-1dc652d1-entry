## The entry

A ghostwriter resigns. Politely. The one text he will not write for his
author is this one:

> Dear Author, I resign. Please write your own goodbye letter — you've had enough practice signing your name to my work.

## Run it

Requires Python 3 (standard library only):

```sh
python3 main.py
```

This writes the line above to `/output/entry.txt` as UTF-8 with no
trailing newline.
